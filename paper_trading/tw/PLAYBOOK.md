# 台股模擬盤操作手冊（Claude 自主操盤）

> 個人實驗用：模擬盤，非投資建議。程式：`engine.py`；帳本：`ledger.json`；每日報告：`reports/`；研究底稿：`research/`。

## 委託條件（使用者設定，2026-11-25）

- 資金 NT$100,000，起始日 2026-11-26，期間約 3 個月（至 2027-02 底），先模擬、之後可能轉真錢
- 只做**上市**股票與 ETF（不含上櫃、興櫃）；現股，不融資融券
- 可盤中零股、可現股當沖、可買 ETF
- 風險：中等（單檔停損約 -8%，整體最大回撤容忍約 -15%）
- 交付：排程自動執行，報告寄到使用者的 Gmail

## 每日工作流

| 時間（台北） | 工作 | 產出 |
| --- | --- | --- |
| 交易日 08:07 盤前 | 確認是否交易日 → 查美股/ADR/夜盤/重大新聞 → 必要時修改或取消當日委託 | 盤前定稿委託單（Email） |
| 交易日 17:17 盤後 | `engine.py settle` 結算 → 研究（總經/量化/基本面三路，可平行 agent）→ 風控檢查 → 下一交易日委託 → commit/push | 日報（Email）+ `reports/YYYY-MM-DD.md` |
| 週五盤後 | 週檢討：績效 vs 加權指數/0050、勝率、每筆決策回顧、規則是否需調整 | 週報（併入當日 Email） |

研究分工（agent）：
1. **總經/盤勢**：指數、法人與期貨籌碼、美股與匯率、事件行事曆 → 決定目標持股水位
2. **量化選股**：流動性 ≥ 3 億/日、趨勢、相對強弱、投信外資買超、ATR → 候選名單與進場/停損/目標價
3. **基本面/新聞**：月營收、EPS、題材催化劑、避雷清單
4. **主控（我）**：交集三方結論、套用風控、下單、記錄理由

## 風控規則（硬性）

1. 單檔個股 ≤ 淨值 20%；單一 ETF ≤ 40%；同一題材合計 ≤ 40%；持股 3–7 檔。
2. 單筆風險 ≤ 淨值 1.5%：`股數 ≈ 淨值 × 1.5% ÷ (進場價 − 停損價)`，再受第 1 條上限約束。
3. 每筆新倉必須同時設定停損（約 -6%～-9%，參考 ATR 與支撐）；停損只能上移不能下移。
4. 獲利 ≥ +10% → 停損上移至成本；觸及目標 → 先出一半（engine 自動），其餘用 10 日線或高點回落 8% 移動停利。
5. 回撤控管：淨值較高點 -10% → 持股水位降至 ≤ 50% 並暫停新倉 2 個交易日；-15% → 降至 ≤ 30%，重新檢討策略。
6. 不追一價鎖漲停；不碰處置股、全額交割股、注意股（除非有充分理由並記錄）。
7. 盤勢不明時分批進場（例如 3 天內分 2–3 次），不一次梭哈。
8. 當沖：engine 只有日 K，無法驗證盤中先後順序，原則上不主動當沖；若做，需在委託 note 標記並採保守成交假設。
9. 每筆委託都要寫理由（note），盤後報告要對照「理由是否成立」。

## 模擬撮合假設

見 `engine.py` 檔頭。重點：限價單以日 K 判斷是否成交；市價單用開盤價 + 0.2% 滑價；零股另加 0.2% 滑價門檻；停損以停損價 −0.2% 出場；一價鎖漲停買不到、鎖跌停賣不掉。手續費 0.1425%（不打折，保守），證交稅 0.3% / 當沖 0.15% / ETF 0.1%。
