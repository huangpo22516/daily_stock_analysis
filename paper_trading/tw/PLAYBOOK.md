# 台股模擬盤操作手冊（Claude 自主操盤）

> 個人實驗用：模擬盤，非投資建議。程式：`engine.py`；帳本：`ledger.json`；每日報告：`reports/`；研究底稿：`research/`。

## 委託條件（使用者設定，2026-11-25）

- 資金 NT$100,000，起始日 2026-11-26，期間約 3 個月（至 2027-02 底），先模擬、之後可能轉真錢
- 只做**上市**股票與 ETF（不含上櫃、興櫃）；現股，不融資融券
- 可盤中零股、可現股當沖、可買 ETF
- 風險：中等偏積極（單檔停損約 -8%，整體最大回撤容忍約 -20%；2026-11-25 依使用者背景由 -15% 放寬：剛出社會、住家裡、總本金約 30 萬、每月可投入 ≥ 1 萬）
- 激進程度依「已驗證的優勢」逐級提高，不依本金大小（見「風險階梯」）
- 交付：排程自動執行，報告寄到使用者的 Gmail

## 每日工作流

| 時間（台北） | 工作 | 產出 |
| --- | --- | --- |
| 交易日 08:07 盤前 | 確認是否交易日 → 查美股/ADR/夜盤/重大新聞 → 必要時修改或取消當日委託 | 盤前定稿委託單（Email） |
| 交易日 10:37、12:37 盤中 | **盤中風控檢查**（只處理事先寫好的觸發條件，見下節）；沒有觸發就什麼都不做、不寄信 | 有動作才寄 Email |
| 交易日 17:17 盤後 | `engine.py settle` 結算 → 研究（總經/量化/基本面三路，可平行 agent）→ 風控檢查 → 下一交易日委託 → commit/push | 日報（Email）+ `reports/YYYY-MM-DD.md` |
| 週五盤後 | 週檢討：績效 vs 加權指數/0050、勝率、每筆決策回顧、規則是否需調整 | 週報（併入當日 Email） |

研究分工（agent）：
1. **總經/盤勢**：指數、法人與期貨籌碼、美股與匯率、事件行事曆 → 決定目標持股水位
2. **量化選股**：流動性 ≥ 3 億/日、趨勢、相對強弱、投信外資買超、ATR → 候選名單與進場/停損/目標價
3. **基本面**：月營收、EPS、評價、題材催化劑、避雷清單
4. **消息/事件**：重大新聞與政策（科技巨頭人事、關稅、出口管制、地緣政治、金管會措施、作帳/MSCI 等季節性資金）→ 事件地圖（證實程度、受惠/受害股、時效、失效條件）
5. **主控（我）**：交集各方結論、套用決策原則與風控、下單、記錄理由與策略標籤
6. **反方審查**（`agents/red_team.md`）：有新買進委託時，只看委託與理由、專門找漏洞；主控須在報告逐條回應
7. **週檢討**（`agents/weekly_review.md`）：每週最後一個交易日，獨立評估決策品質、校準、規則遵守，產出 `research/weekly/`

委託定案流程：研究 → 擬委託 → `python dq_check.py`（資料交叉比對、處置股、規則檢查，有 ERROR 不得送出）→ 反方審查 → 修改或回應 → 定案寫入報告。
事件行事曆：`research/calendar.md`，盤前/盤中/盤後都要讀，發現新事件就更新。

## 盤中風控協議（2026-11-25 試行 1–2 週）

盤中**不臨時找新機會**，只處理下列事先登記的觸發條件：

1. **大盤急跌**：加權指數盤中跌幅 ≥ 3%，或跌破報告中列出的關鍵價位（目前 36,000）→ 取消尚未成交的買單（`cancel <id> --at HH:MM`），並依前一份報告的「條件式預案」行動（例如避險）。
2. **持股失效條件發生**：持股在 `--invalid` 寫的情境盤中成真（例如 301 對台稅率公布 > 15%、作證爆出不利新事證）→ 出場（`order SELL ... --after HH:MM`）或上移停損（`setstop <code> <價> --at HH:MM`）。
3. **待成交買單的理由消失** → 盤中取消。
4. **條件式預案**：前一份報告中事先寫好「若 X 則買 Y」的條件單，條件成立才執行；其他新倉一律等盤後研究。

時間戳記：決策時間取台北現在時間，向上取整到下一根 5 分鐘 K（例如 10:41 → `--after 10:45`），結算時只用該時間之後的價格，避免偷看答案。
報價延遲：Yahoo 盤中報價可能延遲，判斷時要考慮。
評估：試行 1–2 週後檢討，比較盤中動作實際的損益與「不動作」的結果，沒有價值就停掉盤中排程。

## 決策原則（使用者要求，2026-11-25）

1. **算費用**：股票來回成本約 0.585%（手續費 0.1425%×2 + 稅 0.3%），ETF 約 0.385%，當沖約 0.435%。
   新倉的「目標報酬 ÷ 來回成本」須 ≥ 5（即至少約 +3%），且報酬/風險比 ≥ 1.5；不為了小波動換股（churn）。
2. **每筆都要理由**：`engine.py order` 強制 `--strategy`、`--note`（理由）、`--invalid`（失效條件）。盤後檢查理由是否仍成立；理由消失就出場，不等停損。
3. **多面向，不只技術指標**：每筆決策至少綜合三面中的兩面以上——
   - 消息/事件面（重大新聞、政策、關稅、科技巨頭人事與財報、地緣政治；先查證，傳聞要標記）
   - 籌碼面（外資/投信/自營、期貨未平倉、融資、借券）
   - 基本面（月營收、EPS、評價）
   - 技術/價格行為（趨勢、相對強弱、量價、支撐壓力）
   - 總經盤勢（決定整體水位）
4. **不必天天交易**：只在有合適機會（符合上述門檻、理由充分）時才下單；沒有就空手觀望，報告中說明「今日不交易」的理由。不為了湊交易而交易。
5. **自我演化**：同時測試多個「策略假設」，每筆交易標策略；每週用 `engine.py stats` 檢討，在 `research/strategy_journal.md` 記錄保留/調整/淘汰的理由。

## 策略假設（實驗中，依結果增刪）

| 標籤 | 假設 | 進場依據 | 出場/失效 | 狀態 |
| --- | --- | --- | --- | --- |
| 事件驅動 | 已證實的重大消息會在 1–4 週內持續反映到受惠/受害股 | 消息查證 + 價格確認（不追鎖漲停） | 消息被否認/反轉、價格不認同 | 實驗中 |
| 投信作帳 | 年底投信作帳與政府護盤期間，投信連買的中大型股相對抗跌 | 投信連續買超 + 基本面不差 | 投信轉賣、跌破支撐 | **淘汰為進場理由**（2026-11-25 回測 H1/H2/H3 樣本外皆不成立，依演化協議第 8 條；投信動向只作流動性參考，既有影子部位照常追蹤到期） |
| 基本面動能 | 月營收加速 + 法人認同的公司，空頭中跌深後反彈較強 | 營收/EPS 動能 + 回測支撐 | 營收轉弱、停損 | 實驗中（回測 H4「證據不足、偏正面」：只作選股加分，營收公布後次月 15 日才用、持有約 20 日、分散；空頭時不因此加碼） |
| 防禦核心 | 高波動空頭期，低 beta 資產（電信、民生、ETF）降低組合波動 | 盤勢 Risk-off | 盤勢轉多時換股 | 實驗中 |
| 超跌反彈 | 恐慌賣壓 + 政策護盤時，短線均值回歸 | 極端乖離 + 護盤訊號 | 短期持有，失敗快砍 | 觀察（尚未啟用） |

（另有「量化動能」：量化篩選前段班，目前只以影子部位追蹤。）

### 籌碼乾淨度（分點作帳／主力拉抬的免費替代檢查，2026-11-27 依使用者要求新增）

券商分點資料需付費（FinMind 付費等級；證交所買賣日報表有驗證碼），目前改用免費替代指標，由 `dq_check.py` 自動檢查：
融資 5 日增幅 > 20%、當沖比 > 50%、爆量（> 20 日均量 3 倍且漲跌 > 5%）、集保千張大戶週減 ≥ 1pt 且人數週增 ≥ 5%（`tdcc_snapshot.py` 每天執行，累積兩週後生效）。
買進命中 ≥ 2 項 = 不得下單；命中 1 項要在報告說明為何仍可買。籌碼指標只作排除，不作買進理由（回測：籌碼追隨無樣本外超額）。
選股範圍維持流動性門檻 3 億（使用者 11/27 決定不擴大到中小型股）。

### 影子部位量測規則（2026-11-27 修訂）

- 成交條件與實單零股相同：最低 ≤ 進場價 × (1 − 0.2%)。
- 到期：未成交 → 記 `missed_ret`（第一天開盤買進到到期日收盤的報酬，衡量「等拉回」的機會成本）；已成交未出場 → 到期日收盤出場並計 R。
- 填機率時要寫出相對零漂移基準 p0 =（進場 − 停損）/（目標 − 停損）高或低的理由；`engine.py stats` 會同時列出 p0 的 Brier。

## 演化協議（防過擬合，2026-11-25 修訂）

> 原本「≥5 筆平倉、勝率 < 40% 就淘汰」的規則已廢除：5 筆交易的勝率幾乎全是雜訊，照它增刪策略等於對雜訊過擬合。

1. **樣本來源分三層**，權重由高到低：
   - **歷史回測/事件研究**（多年台股資料、樣本外驗證）：可機械化的規則（如投信連買、MSCI 納入、年底作帳、月營收加速）先用歷史資料檢驗，訓練期與測試期分開。
   - **影子部位**（`engine.py shadow`）：每個看到但沒做的點子、每個規則訊號都記錄假想進出，不占資金，擴大樣本並降低「只記得做過的交易」的選擇偏誤。
   - **實單**：樣本最少，只用來驗證執行面（成交、滑價、費用）與確認。
2. **先登記、後檢驗**：每個策略的假設、進出場規則、評估指標，都要在使用前寫進本檔（git 有時間戳記）；事後不得為了解釋結果而改定義。
3. **只在週檢討改規則，一次只改一件事**，寫明經濟邏輯（為什麼這樣改市場上應該有效），不因單筆輸贏改規則；參數盡量少、取整數，不微調到「剛好擬合最近幾週」。
4. **評估看過程，不只看結果**：每筆平倉檢討「理由是否被驗證」，分成「對的理由賺錢/錯的理由賺錢（運氣）/對的理由虧錢（可接受）/錯的理由虧錢（要修正）」。
5. **機率校準**：每筆實單與影子都要寫事前機率 `--prob`（先到目標的機率），用 Brier score 衡量判斷力；這個指標累積樣本比勝率快得多。
6. **對照基準**：績效同時比較 (a) 加權指數、(b) 同曝險基準（相同持股比重的大盤報酬，`bench_adj`），超額報酬才算選股/擇時能力。
7. **盤勢標記**：每筆交易記錄當時盤勢（Risk-on/off），策略好壞要在同類盤勢下比較；三個月可能只經歷一種盤勢，結論要保守。
8. **淘汰/升級門檻**：影子 + 實單合計 ≥ 20 筆、且平均 R 明顯 < 0（或歷史回測樣本外不成立）才淘汰；新策略需影子 ≥ 10 筆平均 R > 0 才升為實單、並從小部位開始。

## 風控規則（硬性）

1. 單檔個股 ≤ 淨值 20%；單一 ETF ≤ 40%；同一題材合計 ≤ 40%；持股 3–7 檔。
2. 單筆風險 ≤ 淨值 1.5%：`股數 ≈ 淨值 × 1.5% ÷ (進場價 − 停損價)`，再受第 1 條上限約束。
3. 每筆新倉必須同時設定停損（約 -6%～-9%，參考 ATR 與支撐）；停損只能上移不能下移。
4. 獲利 ≥ +10% → 停損上移至成本；觸及目標 → 先出一半（engine 自動），其餘用 10 日線或高點回落 8% 移動停利。
5. 回撤控管：淨值較高點 -12% → 持股水位降至 ≤ 50%、風險階梯降一階並暫停新倉 2 個交易日；-20% → 降至 ≤ 30%，回到第一階並重新檢討策略。

## 風險階梯（事先登記，達標才升級，不臨時決定）

| 階 | 升級條件（全部成立） | 單筆風險 | 單檔上限 | 同題材上限 | 持股水位上限 |
| --- | --- | --- | --- | --- | --- |
| 1（目前） | 起始 | 1.5% | 20% | 40% | 依盤勢（Risk-off ≤ 30%、中性 ≤ 60%、Risk-on ≤ 90%） |
| 2 | 實單＋影子平倉 ≥ 20 筆；Brier < 0.23；扣費後同曝險超額報酬 > 0 | 2.0% | 25% | 50% | 同上，Risk-on 可到 100% |
| 3 | 第 2 階後再累計 ≥ 20 筆仍符合；至少一個策略回測樣本外成立 | 2.5% | 30% | 60% | 可集中 3–4 檔 |

降階：淨值回撤 ≥ 12%，或近 20 筆 Brier ≥ 0.25（判斷力不如擲硬幣）→ 降一階。升降階都只在週檢討時決定，並寫進 `research/strategy_journal.md`。
6. 不追一價鎖漲停；不碰處置股、全額交割股、注意股（除非有充分理由並記錄）。
7. 盤勢不明時分批進場（例如 3 天內分 2–3 次），不一次梭哈。
8. 當沖：engine 只有日 K，無法驗證盤中先後順序，原則上不主動當沖；若做，需在委託 note 標記並採保守成交假設。
9. 每筆委託都要寫理由（note），盤後報告要對照「理由是否成立」。

## 模擬撮合假設

見 `engine.py` 檔頭。重點：**優先用 Yahoo 5 分鐘 K 依時間順序撮合**（委託生效時間、盤中取消、停損/停利誰先觸發；同一根 K 先停損後停利；當日新買進的部位從下一根 K 才檢查），拿不到 5 分鐘 K 才退回日 K；市價單用開盤價 + 0.2% 滑價；零股另加 0.2% 滑價門檻；停損以停損價 −0.2% 出場；一價鎖漲停買不到、鎖跌停賣不掉。手續費 0.1425%（不打折，保守），證交稅 0.3% / 當沖 0.15% / ETF 0.1%。

## 指令速查

```bash
cd paper_trading/tw
python engine.py status
python engine.py order BUY 2330 10 --limit 2100 --stop 1950 --target 2400 --note "理由" --date 2026-11-26
python engine.py cancel 3                      # 盤前取消
python engine.py cancel 3 --at 10:45 --reason "大盤急跌"     # 盤中取消（之前已成交的不受影響）
python engine.py order SELL 2330 5 --after 10:45 --note "失效條件成立" --date 2026-11-26   # 盤中市價出場
python engine.py setstop 2330 2100 --at 10:45 --date 2026-11-26                       # 盤中上移停損
python engine.py shadow 2412 --entry 162.5 --stop 153 --target 171 --strategy 防禦核心 --prob 0.4
python engine.py stats
python engine.py settle --date 2026-11-26
```
